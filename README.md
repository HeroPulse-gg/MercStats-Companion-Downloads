# MercStats Companion downloads

This repository is the official, downloads-only home for the MercStats Companion beta. It contains compiled release packages and release notes; the Companion source code is not published here.

## Download

Open the [latest release](https://github.com/HeroPulse-gg/MercStats-Companion-Downloads/releases/latest) and choose the package for your computer:

| Platform | Release asset |
| --- | --- |
| Windows 10/11 (x64) | `MercStats-Companion-Setup-win-x64.exe` |
| macOS Apple silicon | `MercStats-Companion-osx-arm64.dmg` |
| macOS Intel | `MercStats-Companion-osx-x64.dmg` |
| Linux (x64) | `MercStats-Companion-linux-x64.tar.gz` |

The website at [MercStats.com/companion](https://mercstats.com/companion) automatically recommends the right package and always links to the newest release.

Beta packages may show an operating-system security warning until platform signing and Apple notarization are configured. Release notes state the signing status for each version.
